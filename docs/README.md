## Scope / 范围

These documents describe the current Linux.do-only, single-active-account
milestone. Background push, Chat, generic multi-site Discourse configuration,
offline write queues, signed distribution, app-store publishing, and GitHub
Releases are outside this milestone.

这些文档描述当前固定 Linux.do、单一活动账号的里程碑。后台推送、Chat、通用多站点
Discourse 配置、离线写入队列、签名分发、应用商店发布和 GitHub Release 不在当前范围。

The removed Flare marketing site, store links, and OAuth callback pages are not
part of FlareDo. This repository does not deploy GitHub Pages.

已移除的 Flare 宣传站、商店链接和 OAuth 回调页面不属于 FlareDo；本仓库不部署
GitHub Pages。
